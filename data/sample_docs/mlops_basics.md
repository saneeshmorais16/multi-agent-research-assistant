# MLOps Basics Notes

MLOps practices help teams move machine learning and AI workflows from experiments into repeatable systems. Useful practices include versioning data, recording evaluation metrics, testing pipelines, and monitoring quality over time.

For AI assistants, evaluation should include groundedness, completeness, citation coverage, and user feedback. Automated tests can check retrieval quality, insufficient-evidence behavior, and structured output schemas.

Deployment should not be claimed unless the system is actually operated for users. Portfolio prototypes should clearly describe sample data, limitations, and what is not implemented.
